# Warning Label for Humans: One Line, Big Laugh

One line (≤160 characters): the safety warning label that should come printed on every human being.

> WARNING: This human runs on three hours of sleep, one coffee, and pure spite. Do not attempt to reason with it before noon.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
